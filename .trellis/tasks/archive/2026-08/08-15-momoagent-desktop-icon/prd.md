# momoagent desktop icon

## Goal

为当前名为 MOMO 的智能体制作一枚可辨识、精致且适合 Windows 桌面使用的应用图标。图标身份应独立于名称和桥梁工程领域，以便后续改名或扩展产品定位时仍可沿用。

## Confirmed facts

- 用户要求图标参考 OpenDesign 的设计语言，并明确选择卡通智能体方向。
- 用户说明产品后期不一定继续使用 MOMO 名称，因此图标不能依赖名称、字母 M 或桥梁意象。
- 现有 `platform-ui/public/favicon.svg` 是 Vite 默认的紫青闪电标记，仓库中没有可复用的 MOMO 专属图标。
- OpenDesign 的 Raycast 设计包适合作为桌面 AI/生产力工具参考：近黑底、高对比、克制留白、单一强调色、细微而非厚重的立体层次。
- 用户指定 Windows 桌面上的 `D:\Users\lenovo\Desktop\MOMO Agent.lnk` 使用新图标；该快捷方式当前启动 `D:\helloagent\momo.cmd`，工作目录为 `D:\helloagent`。

## Requirements

- 交付一枚新的正方形桌面应用图标，主体在缩小到 32 px 时仍易于识别。
- 图标主体为没有文字、没有字母标记的卡通智能体；使用简洁头部轮廓、两枚高对比眼睛和一枚小型状态光点，表达友好、可靠与反应迅速。
- 采用克制的 OpenDesign 风格：近黑圆角方形底、暖白智能体主体、单一珊瑚红状态光点、细微内阴影和边缘高光；不使用复杂纹理或多种高饱和色。
- 不复用 Raycast、Vite 或其他品牌的标志资产，也不表现桥梁、工程设备或名称相关字符。
- 最终提供适合 Windows 使用的 PNG 与 ICO 文件；图标应有透明背景，方便放置于不同桌面壁纸上。
- 将指定的 `MOMO Agent.lnk` 快捷方式图标替换为生成的 ICO 文件，并保持启动目标、参数、工作目录和说明不变。

## Acceptance Criteria

- [ ] 在深色和浅色背景上均可清晰辨识，边缘干净且无明显色边。
- [ ] 主体由少量清晰形状构成，能在 32 px、48 px 与 256 px 尺寸保持可读。
- [ ] 图标不含文字、水印、现有品牌标志或易混淆的 Vite 默认闪电图形。
- [ ] 输出包含一张透明 PNG 和一份含常用尺寸的 Windows ICO。
- [ ] 图标主体为可脱离 MOMO 名称长期使用的卡通智能体，不含桥梁或工程行业特定物件。
- [ ] 指定快捷方式的 `IconLocation` 指向生成的 ICO 文件，且其启动设置保持不变。

## Out of scope

- 不修改应用前端或安装包配置。
- 不在本任务中制作整套品牌视觉系统或多枚变体图标。
